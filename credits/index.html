Vos données

Sur la page Matériel, les cases cochées sont enregistrées dans le stockage local de votre navigateur, séparément pour chaque sortie. Elles restent sur cet appareil, sans envoi automatique. Un lien partagé contient une copie des cases cochées que le destinataire peut modifier sur le site. Le PDF exporté reprend ces cases et ce lien. « Vider le sac » efface la progression de la liste sélectionnée ; « Annuler » permet de la restaurer immédiatement. Effacer les données du site dans votre navigateur supprime toutes les listes enregistrées.

Le formulaire prépare votre demande dans votre navigateur. Il n’enregistre pas vos informations dans une base de données du site. Lorsque vous continuez vers WhatsApp, les champs saisis sont transmis à ce service dans le lien du message prérempli. Vous décidez ensuite de l’envoyer.

Les échanges se poursuivent avec Joshua par WhatsApp, téléphone ou e-mail. Pour toute question concernant vos informations, contactez-le à l’adresse ci-dessus. Le site n’intègre aucun outil de suivi publicitaire ni de mesure d’audience. Les services externes ouverts depuis ce site appliquent leur propre politique de confidentialité.
